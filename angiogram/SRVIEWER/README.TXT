
Reporting Tool
========================================================================================

System Requirements
-------------------

- 128 MB RAM (minimum), 256 MB RAM (recommended)
- 1024 x 768 (minimum), 1280 x 1024 (recommended) screen resolution
- Microsoft(R) Windows(R) 2000 or XP
- Internet Explorer version coming with the standard installation (or higher)
- Sun Java (TM) Runtime Environment, Standard Edition version 1.5.0_22
